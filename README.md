# BeraberGidelim

**Don't want to go alone? Go together.** BeraberGidelim is an event-based social discovery app. People who want to attend an event but don't want to go alone meet in that event's chat and go together.

## Features

- Event list and event detail pages, each with its own chat (`/etkinlikler`, `/etkinlik/[id]`)
- Create an event (`/olustur`)
- User profiles (`/profil`, `/kullanici/[id]`)
- Premium page (`/premium`)

## Stack

Next.js 16 · React 19 · TypeScript · Tailwind CSS 4 · Expo (React Native) mobile client in `mobile/`

## Run

```bash
npm install
npm run dev     # http://localhost:3000
```

Mobile client: see `mobile/`.
